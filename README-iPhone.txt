DAYGO — iPhone version

This package is a Progressive Web App (PWA) prepared for iPhone.

IMPORTANT:
iPhone requires the app to be hosted on a secure HTTPS website before Safari can add it to the Home Screen.

INSTALL ON IPHONE:
1. Put these files on an HTTPS web host.
2. Open the DayGo website in Safari on the iPhone.
3. Tap the Share button.
4. Choose “Add to Home Screen”.
5. Tap “Add”.
6. DayGo will appear as an app icon on the Home Screen.

This version includes:
- DayGo cozy logo
- iPhone app icon
- Standalone app mode
- Mobile layout
- Offline caching after first load
- Customization features
- Tasks, calendar, goals and achievements

APP STORE:
Publishing a native iPhone app to the App Store requires an Apple Developer account and Apple signing/build tools (normally Xcode on a Mac). This package is the quickest way to get the current DayGo prototype onto an iPhone without App Store publishing.
